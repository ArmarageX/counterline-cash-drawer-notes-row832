Privacy and static-site behavior

What these static pages do, what they do not collect, and what hosting infrastructure may record when files are requested.

Mara Ellis · fictional editorial persona
Published 11 October 2026 · desk-based guidance

Practical decisions for a cash checkout.

The complete overviewMethod and limitationsContact availability

Counterline Notes consists of static HTML pages, a local style sheet, a small local JavaScript file, four images and crawl-discovery files. There is no application account, checkout, reader form, comment system or publication database behind these pages. The site's own code does not ask for your name, email address, payment details, location or cash records. The contact page offers no monitored intake route, so it should not be interpreted as a way to submit personal information.

What the authored pages do

Navigation links load another page. A native expandable guide menu exposes the six guide links, and a local script allows it to be closed with the Escape key. These actions do not submit entries to the publication. The authored code does not set cookies, use local storage, load analytics, embed advertisements, include tracking pixels or call an external font service. Images, styles and the navigation enhancement are requested as ordinary site files.

This description concerns the files authored for the publication. It is not a promise that the entire internet delivery path is log-free. Your browser, network operator, security software or extensions may have their own behavior. Browser history and caching may retain visited pages or downloaded files on your device. Those features are controlled by the relevant software and settings, not by a reader account on this site.

Hosting and network requests

The planned hosting service is GitHub Pages. When a published page is requested, the hosting provider and its delivery infrastructure may process technical information such as the requesting IP address, request time, requested path, browser information and security or abuse signals. Provider access and retention practices are governed by the provider's policies. The publication does not control those infrastructure logs and does not offer a mechanism here to inspect or erase them.

This privacy explanation is written for the intended static deployment and does not assert that publication has already occurred. If you are viewing a local preview, its local server may record requests in its own process output, and it is not the public hosting service. The pages themselves remain static in either setting. A secure connection to a public host protects traffic in transit according to that connection; it does not eliminate server-side technical records or make a visitor anonymous to every intermediary.

Links and your own information

Following an external reference takes your browser to another service governed by that service's practices. A browser may transmit a referring origin according to the page's referrer policy and its own settings. We use a restrictive cross-origin referrer policy in the authored pages, but do not claim control over the destination. Read the destination's policies before providing information there. Internal guide and trust links simply request another file from this publication's location.

Do not enter confidential information into browser tools or public forums merely because you arrived from an informational guide. Private notes you keep while reading are your responsibility and are not submitted through these pages. If you copy a passage into another application, that application's processing is outside this site's authored behavior. We do not offer account-based access, deletion or data-export requests because there is no reader account or intake database here.

The About page explains the fictional editor and generated concept images, and the Contact page states the absence of a monitored communication route. Return to the checkout overview for the articles. If the authored site later adds features that collect information, this explanation would need revision before those features could be accurately described; it should not be read as a blanket assurance about an unspecified future service.
